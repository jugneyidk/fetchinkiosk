# Roadmap

## MVP

- Native Android app with one Activity.
- XML UI and ViewBinding.
- WebView loads one configured HTTPS URL.
- Explicit domain allowlist.
- Unsafe schemes blocked.
- Immersive fullscreen.
- Device Owner and Lock Task support.
- Hidden admin gesture plus PIN boundary.
- Basic offline/error states.
- ADB provisioning documentation.
- URL policy unit tests.

## Version 1

- Secure local device configuration.
- Admin maintenance menu.
- PIN verification with Keystore-backed material or remote validation.
- Lock Task package allowlisting.
- Boot recovery behavior.
- WebView renderer recovery.
- Instrumented WebView tests.
- Real tablet validation matrix.

## Later Improvements

- QR provisioning.
- MDM/EMM enrollment and managed config.
- Remote configuration by branch/device.
- Controlled remote updates.
- Privacy-reviewed telemetry.
- Fleet dashboard.
- Multi-branch administration.
- Offline support for selected pages only if web system supports it.
- Printer, camera, scanner, or payment peripherals after explicit requirements.

## Out Of Scope Until Approved

- General browser features.
- Multiple tabs.
- Arbitrary downloads.
- File uploads.
- Embedded production secrets.
- Custom TLS bypass.
